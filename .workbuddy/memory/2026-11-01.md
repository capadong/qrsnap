## QrSnap — Avalonia 二维码截屏识别工具（.NET 10）

- 工程：`QrSnap/`（Avalonia 11.3.12 MVVM + net10.0），测试：`QrSnap.Tests/`（21 项全过），发布：`publish/QrSnap.exe`
- 架构：Services/QrDecoder（ZXing.Net + 多轮重试：灰度/放大/静区补偿/Otsu二值化/锐化）、ContentParser（URL/WiFi/vCard/邮箱/电话）、Platform 抽象（IScreenCapture + Windows BitBlt 实现；IGlobalHotkeyService 独立线程实现）、CaptureCoordinator 编排、CaptureOverlay 自绘截图选区层、ResultWindow 结果窗
- 热键 Alt+Q：RegisterHotKey(hWnd=NULL) + 独立 STA 线程消息循环；第一版自建窗口类导致进程约 30-60 秒后无故退出，改为 NULL 窗口方案后稳定
- 关键坑：DPI 缩放 150% 下 Avalonia 窗口 Width 是逻辑像素，覆盖层尺寸须 `RenderScaling` 换算，选区导出乘回 scaling，否则选框与实际像素错位、识别失败
- 端到端冒烟测试通过：`tools/ScreenShot`（模拟全屏二维码 + 鼠标拖拽框选 + 双击），解码结果与预设一致，结果窗正常弹出
- 用户决定：.NET 10、Windows 优先（接口留跨平台）、热键 Alt+Q、第一版完整主流程
